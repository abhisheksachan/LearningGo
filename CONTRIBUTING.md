# Contributing to Learning Go

Thank you for your interest in contributing! This repository is for learning Go programming through hands-on examples.

## How to Contribute

1. **Fork the repository** on GitHub
2. **Create a feature branch** from `main`
3. **Make your changes** following the existing code style
4. **Test your code** by running `go run main.go` in the relevant module
5. **Commit your changes** with clear, descriptive messages
6. **Push to your fork** and **create a Pull Request**

## Code Style

- Follow standard Go formatting (`gofmt`)
- Use meaningful variable and function names
- Add comments for complex logic
- Keep examples simple and educational

## Module Structure

Each learning module should be in its own folder (e.g., `15functions/`) with:
- `go.mod` file
- `main.go` with examples
- Clear, commented code

## Reporting Issues

Use the issue templates for bug reports and feature requests.
